# Pearlet logo

`brand/pearlet-icon.svg` is the hand-built source for the Pearlet mark: a nacre pearl set into a shallow recess in a pale nacre tile. The iOS `AppIcon` and `LaunchLogo` sets and the Android launcher and launch images are rendered from it with `rsvg-convert`. The in-app `PearletMark` component in `src/PearlDesign.tsx` draws the same mark.

# PRL glyph

`PrlGlyph` in `src/PearlDesign.tsx` reproduces the official Pearl mark from `apps/apps/pearl-desktop-wallet/resources/pearl-logo.svg` in [pearl-research-labs/pearl](https://github.com/pearl-research-labs/pearl). It identifies the PRL currency next to balances.
